# Sources de l'exercice 22

| Élément | Origine |
|---|---|
| Les trois cas, `extrait-licence.js`, `journal-exemple.txt` | Inventés pour la formation. La licence GPL-3.0-or-later est une licence réelle ; l'auteur et l'atelier sont fictifs |
| Conditions d'utilisation d'Anthropic | [Conditions pour les particuliers](https://www.anthropic.com/legal/consumer-terms), entrées en vigueur le 08/10/2025. Phrase de la section 4 : « we assign to you all our right, title, and interest (if any) in Outputs », mot à mot « nous vous cédons tous nos droits sur les sorties, s'il y en a ». Pour les offres d'entreprise (API, Team, Enterprise), les [conditions commerciales](https://www.anthropic.com/legal/commercial-terms), section B, lues le 15/11/2026 : « Customer […] owns its Outputs », avec la même cession « (if any) ». Anthropic ne garde donc aucun droit sur le code produit ; « s'il y en a » ne dit pas qu'il y en a |
| Documentation GitHub | [Suggestions de code, correspondance avec le code public](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides), lue le 02/11/2026 : les correspondances avec du code public peuvent être bloquées ou montrées avec des informations de licence si elle est trouvée ; la comparaison cherche du texte identique (la proposition et environ 150 caractères autour) dans le code public hébergé sur GitHub, sans les dépôts privés ni le code publié ailleurs ; quand une proposition qui correspond est acceptée telle quelle, Copilot garde l'adresse du code d'origine et la licence détectée (page relue le 15/11/2026) ; dans le chat, une référence peut s'afficher sous la réponse si le réglage l'autorise ; les journaux de session d'agent portent un lien vers le code correspondant ; les correspondances sont rares (moins d'un pour cent des suggestions en ligne). La page ne dit rien sur la propriété des suggestions |
| Droit français | [Code de la propriété intellectuelle](https://www.legifrance.gouv.fr/codes/texte_lc/LEGITEXT000006069414/), lu sur Légifrance le 15/11/2026. Il ne contient aucun article sur l'IA. L111-1 : l'auteur d'une œuvre de l'esprit a un droit de propriété « du seul fait de sa création ». L112-2, 13° : les logiciels sont des œuvres de l'esprit. L113-1 : l'auteur est, « sauf preuve contraire », celui sous le nom de qui l'œuvre est divulguée. L113-9 : les droits sur le logiciel créé par des « employés dans l'exercice de leurs fonctions » sont « dévolus à l'employeur ». L131-2 : « Les contrats par lesquels sont transmis des droits d'auteur doivent être constatés par écrit ». L131-3 : la transmission suppose que « chacun des droits cédés fasse l'objet d'une mention distincte dans l'acte de cession ». Ces règles valent pour tout logiciel, écrit avec ou sans IA |
| Condition d'originalité | [Directive 2009/24/CE](https://publications.europa.eu/resource/celex/32009L0024), article 1er, paragraphe 3 : un programme est protégé « s'il est original, en ce sens qu'il est la création intellectuelle propre à son auteur » ; article 2, paragraphe 1 : l'auteur est « la personne physique ou le groupe de personnes physiques ayant créé le programme ». [Cour de cassation, assemblée plénière, 7 mars 1986, n° 83-10.477](https://www.legifrance.gouv.fr/juri/id/JURITEXT000007016934) : « un effort personnalisé allant au-delà de la simple mise en oeuvre d'une logique automatique et contraignante ». Lus le 15/11/2026 |
| Rapport américain | US Copyright Office, [« Copyright and Artificial Intelligence, Part 2: Copyrightability »](https://www.copyright.gov/ai/Copyright-and-Artificial-Intelligence-Part-2-Copyrightability-Report.pdf), 29/01/2025, résumé et conclusion lus le 15/11/2026. Il vaut pour les États-Unis : ce qui est purement généré n'est pas protégé ; un prompt seul ne suffit pas (« prompts do not alone provide sufficient control ») ; ce qu'un humain a choisi, arrangé ou modifié peut l'être ; tout se juge au cas par cas |
| Ce que ces textes ne disent pas | Aucun ne dit si du code produit par un outil d'IA remplit la condition d'originalité, ni à partir de quelle part de travail humain. La consigne ne vous demande pas d'en conclure. Aucun texte de cet exercice n'est un avis juridique |
